# Git Viewer

Desktop git client (Electron + Angular 22 + Tailwind 4 + spartan/ui "luma") laid out like the Visual Studio Git Repository window:

- **Left**: branches as a folder tree — local, remotes, tags. Click = show history, double-click = checkout, right-click = checkout / new branch / merge / rebase / delete.
- **Center**: commit history with graph (current branch, any selected ref, or all branches), filter, commit details and diffs below. Right-click a commit for new branch, checkout, cherry-pick, revert, reset, copy ID.
- **Right**: commit box (commit staged / commit all / amend), staged and unstaged files (stage, unstage, discard), stashes (stash all, apply, pop, drop).
- Fetch / pull / push in the header, light / dark / system theme toggle, recent repositories.

## Run

```bash
npm install
npm start                      # build Angular, then open the app
npx electron . C:\path\to\repo # open a repo directly (after a build)
```

Development with live reload: run `npm run dev` (ng serve) and, in another terminal, `npm run dev:electron`.

Graph layout tests: `npm run test:graph`.

## Windows installer

`npm run dist` builds Angular and packages it with electron-builder into `release/Git Viewer Setup <version>.exe`
(NSIS; `release/win-unpacked/` holds the unpacked app). The installer adds Start menu and desktop shortcuts and an
"Open in Git Viewer" entry to the Explorer context menu of folders (removed on uninstall). Only `electron/` and
`dist/git-viewer/browser/` go into the package. The icon is `build/icon.svg`, rendered to `build/icon.png` by
`npx electron build/render-icon.cjs build`.

## How it works

- `electron/main.cjs` runs `git` with `execFile` (no shell) for an allowlist of subcommands; the renderer reaches it only through `window.api` from `electron/preload.cjs`.
- `src/app/git.service.ts` holds all state as signals and parses git output.
- `src/app/graph.ts` assigns lanes and line segments for the commit graph.
- spartan helm components live in `libs/ui` (generated by `@spartan-ng/cli`, style set in `components.json`).
